Install Offline Maps

  1. Download a compatible MUI map ZIP from Oxed's Map Tile Downloader.
  2. Turn the T-Deck off, remove its microSD card, and insert the card into your computer.
  3. Choose the downloaded ZIP below, enter a map name and pack ID, and wait for local validation.
  4. Click Install and Enable, then choose the mounted SD-card root.
  5. Safely eject the SD card, return it to the T-Deck, power it on, and open Maps.
Before installing: close all other Pyxis flasher tabs or windows, and do not run the command-line installer against this same mounted card at the same time. The cross-tab lock coordinates only tabs of this flasher in the same browser profile; it cannot see the CLI or other browsers.

After installing: wait for the verified completion message, then safely eject the card. If activation fails after a pack was published, retry with the exact same ZIP and the same name and pack ID.

Existing unrelated SD-card files are preserved. Map tiles are validated locally and are never uploaded.

Source profile and style are read from the selected MUI ZIP. Rootless XYZ ZIPs default to OSM Bright; change the style above if needed.

Compatible packs of the same style are enabled together. The newest pack takes priority where coverage overlaps.

Choose a ZIP to validate it locally. No tiles are uploaded.

Requirements

  • Browser: Chrome, Edge, or Opera (Web Serial API required)
  • Device: LilyGO T-Deck Plus (ESP32-S3, 8MB Flash)
  • Cable: USB-C data cable (not charge-only)

How It Works

  • 1. Connect T-Deck via USB-C
  • 2. Click "Flash Firmware" and select the serial port
  • 3. Wait for the firmware to be written
Tip: By default, only the firmware is updated - settings and messages are preserved. Check "Full install" for a clean wipe.
